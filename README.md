# MapHelperTelegramBot 📍

[English version](README_eng.md)

Цей бот допомагає орієнтуватися в будівлі, знаходити потрібні кабінети та будувати маршрути від найближчих орієнтирів.

## 🛠 Доступні команди

- **/start** - Розпочати роботу з ботом, виклик головного меню.
- **/help** - Отримати довідку щодо використання бота.
- **/info** - Переглянути інформацію про бота.
- **/floor** - Швидкий доступ до вибору поверху та кабінету.

## 🚀 Як користуватися

Процес побудови маршруту складається з трьох простих кроків:

### 1. 🎯 Куди ви хочете потрапити? (Вибір кабінету)
У головному меню натисніть **"FLOOR"**. Бот запропонує вам обрати потрібний поверх зі списку.
Далі після вибору поверху бот запропонує вам обрати потрібний кабінет зі списку або ввести його номер.

### 2. 🏢 Де ви зараз? (Вибір поверху)
Оскільки маршрут залежить від того, де ви знаходитесь, бот запитає у вас поверхи.
- Якщо ви на тому ж поверсі, що й кабінет, виберіть цей поверх.
- Якщо ви на іншому поверсі, оберіть його, щоб бот побудував маршрут від сходів або ліфта.

### 3. 🚩 Точка відліку (Вибір орієнтиру)
Після вибору поверху бот покаже список відомих **орієнтирів** (наприклад: *"Головний вхід"*, *"Сходи №1"*, *"Бібліотека"*).
Оберіть той, який знаходиться найближче до вас.

Після цього бот надішле вам детальний опис маршруту з зображенням!

## 🧑‍💻 Технології

- **Java 21** - мова програмування
- **Telebof 1.3.0** - бібліотека для роботи з Telegram Bot API
- **Hibernate 6.4.4.Final** - ORM для роботи з базою даних
- **PostgreSQL** - база даних
- **Caffeine 3.1.8** - кешування (другий рівень кешу Hibernate)
- **Maven** - система збірки

## 📋 Вимоги

- Java 21 або вище
- Maven 3.8+
- PostgreSQL база даних
- Telegram Bot Token

## ⚙️ Налаштування

1. Створіть файл `.env` у корені проєкту:
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

2. Налаштуйте підключення до бази даних у `src/main/resources/META-INF/hibernate.cfg.xml`

## 🚀 Запуск

### Збірка проєкту:
```bash
mvn clean package
```

### Запуск:
```bash
java -jar target/telegram-bot-1.0.0.jar
```

Або безпосередньо через Maven:
```bash
mvn clean compile exec:java -Dexec.mainClass="ua.notion.telegrambot.TelegramBotApplication"
```

## 📁 Структура проєкту

```
src/main/java/ua/notion/telegrambot/
├── config/         # Конфігурація Hibernate
├── constants/      # Константи
├── controller/     # Контролери
├── handler/        # Обробники повідомлень та callback

├── repository/     # DAO шар для роботи з БД
├── service/        # Бізнес-логіка
└── util/           # Утилітні класи
```
